# One-Line Office Joke Laugh-Off

A tiny TypeScript program that writes one original one-line office joke to
`/output/entry.txt`: the office fridge as a crime scene where the victim, the
suspect, and the detective are all stealing each other's lunch.

The joke: **"The office fridge is a crime scene where the victim, the suspect, and the detective all steal each other's lunch."**

Run with `node main.ts` (Node 22+).
